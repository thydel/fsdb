### 2. Explanation of the `fill` CTE (Time-Series Densification)

Your intuition to generate a full range and join it with zero-filled deltas is
correct and can be done natively inside DuckDB:

1.  **Generate the Time Grid:** Use DuckDB's `generate_series` function to
    generate all buckets between the minimum and maximum dates in the current
    dataset:

    ``` sql
    SELECT generate_series AS date FROM generate_series(
      (SELECT MIN(date) FROM {prev}),
      (SELECT MAX(date) FROM {prev}),
      INTERVAL '1 month' -- or '1 hour', etc.
    )
    ```

2.  **Generate the Key Grid (Cross Join):** If the pipeline groups by other
    dimensions (like `path` or `server`), get the distinct set of those keys
    from the dataset and `CROSS JOIN` them with the generated time range. This
    creates a grid representing every time bucket for every dimension key.

3.  **Left Join and Zero-Fill:** `LEFT JOIN` the grid with the actual dataset.
    Use `COALESCE(actual.size, 0) AS size` and `COALESCE(actual.cnt, 0) AS cnt`
    to fill missing buckets.

When `cumul` (running total) is applied to this zero-filled dataset, the
cumulative size and count will carry over unchanged in the missing buckets,
showing a correct flat line during periods of no modifications.
